# **It's in Your Eyes**  
**Awareness and Control EOG-Based HCI Flutter Desktop Application**  
*(Graduation Project - Funded by ITIDA)*  

---

## **Overview**  
"It's in Your Eyes" is a desktop application designed to control interfaces using **electrooculography (EOG) signals**. The app leverages **machine learning** and **deep learning** techniques to process EOG signals, enabling users to interact with their systems seamlessly.  

This project was funded by **ITIDA** as part of my graduation project.  

---

## **Key Features**  
- Control interfaces using **EOG signals** for hands-free interaction.  
- Real-time signal processing and system control.  
- Seamless and responsive user experience built with **Flutter**.  
- Integration of **pyautogui** for automated system control.  

---

## **Toolkits & Technologies**  
- **Frontend:** Flutter (`http`, `provider`, `audioplayers`, `flutter_azure_tts`, `flutter_tts`, `tflite_flutter`).  
- **Backend:** Python.  
- **Automation:** `pyautogui` for system control.  
- **Data Science & Analysis:** Machine learning and deep learning for signal processing.  
- **Models:** CNN, VGG16, ResNet18/52, Inception architectures.  
- **Model Optimization:** Early Stopping, ModelCheckpoint callbacks.  

---

## **How It Works**  
1. EOG signals are captured and processed using **machine learning models**.  
2. The processed signals are used to control the system interface.  
3. The app provides a seamless and responsive experience for users.
